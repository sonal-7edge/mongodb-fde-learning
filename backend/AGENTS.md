# Rules for AI coding agents in this repo

Copy this file to `CLAUDE.md` (Claude Code) or keep it as `AGENTS.md` (other agents).
These rules cover `backend/`; run every command from that folder. `frontend/` is a separate app.

This is a **teaching repo** for MongoDB. Readable code beats clever code.

## Always

1. **Explain each change before making it**: which file, why, and which access pattern (docs/access-patterns.md) it serves.
2. **Run `make test` after each change** and report failures with their output. Don't claim success without it.
3. **Edit only the root `entities/` and `shared/`.** The copies in `services/*/entities` and `services/*/shared` are generated by `make sync` and are read-only.
4. **Raw external API keys stay inside `services/*/sources/`.** Translators map them to our domain names; no other folder may mention them (a test enforces this).
5. Plain JavaScript (CommonJS: `require` / `module.exports`) with JSDoc. No TypeScript, no build step. Tests are `.test.mjs` because Vitest must be `import`ed; they load app code with `createRequire`.
6. Request validation uses Joi schemas through `shared/validate.js`. Field names are snake_case.
7. Never create indexes from application code at startup. Every index is added deliberately, for a named access pattern.
8. One handler per file in `services/<service>/routes/` (exported with `module.exports.<name>`). Every endpoint is registered in `app.js` with its `auth` and Joi `validate(...)`, so all routes are visible in one place. Joi schemas live in `utils/joi_schema.js`.

## Never

- **Never edit anything in `test/exercises/`.** Those tests are checksum-guarded. Change the application code until they pass.
- **Never print, log or commit `.env`** or the value of `MONGODB_URI` / `JWT_SECRET`.
- Never add a dependency without asking.
- Never use `skip()` for pagination beyond page 1; use the cursor helpers in `shared/pagination.js`.

## Useful commands

```bash
make test                   # all tests, in-memory MongoDB
make dev                    # local server with auto-restart
TOKEN=$(make -s token)      # access token for curl
curl -H "Authorization: Bearer $TOKEN" "localhost:3004/api/...&explain=true"
```
